CYDash
=======

## An OBD2 digital dashboard using the ESP32 "Cheap Yellow Display" (CYD)

This project is _not_ a fork of the repo at: https://github.com/donalexvalluvassery/cyd-obd, 
but uses the code from that project as a starting point. I did not make a fork of that repo
since I do not plan on committing code back to that project, but definitely want to give the
original author credit. 

This is a digital dash for gas powered vehicles. It uses Bluetooth to connect to an ELM327 based BT dongle
and reports RPM, Temp, Battery Voltage, Load, and Intake Air Temp (if available)
